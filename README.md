# 한칸이야기 (DrawTale)

**아이가 그린 그림이 주인공이 되어, 아이가 고른 이야기 속에서 움직인다.**

글자를 읽지 못해도, 빈 종이 앞에서 무엇을 쓸지 떠올리지 못해도 이야기를 만들 수 있게 한다.
시각적 · 단계적 지원이 필요한 아동을 위한 서비스다.

---

## 어떻게 쓰나

```
그림을 올린다  →  캐릭터가 된다  →  네 칸을 고른다  →  이야기와 영상이 나온다
```

1. **그림을 올린다** — 종이에 그린 그림을 찍거나, 화면에 직접 그린다
2. **캐릭터가 된다** — AI가 그림에서 사람 모양과 관절 15개를 찾는다.
   AI가 자신 없어 하면 그때만 어른이 관절을 고쳐 준다
3. **네 칸을 고른다** — 장소 → 문제 → 행동 → 결과를 카드로 고른다. 글자를 못 읽어도 읽어 준다
4. **이야기와 영상이 나온다** — 고른 네 칸이 네 문장이 되고, 아이 그림이 그 이야기 속에서 움직인다
5. **순서를 맞춰 본다** — 문장을 섞어 놓고 다시 순서대로 놓아 본다

## 이 서비스의 첫 번째 원칙

> **AI가 동화를 대신 만들어 주지 않는다. 이야기를 구성하는 주체는 아이다.**

AI는 아이가 고른 네 칸을 문장으로 다듬고, 아이 그림을 움직이게 하는 일만 한다.
기능을 더하거나 화면 문구를 정할 때 이 문장을 기준으로 삼는다.

그리고 **기본 흐름은 아이가 스스로 진행한다.** 어른은 AI가 확신하지 못하는 단계에서만 들어온다.

아이 화면에는 `발달장애` `특수교육` `장애` `진단` `치료` 같은 말과 기술 용어를 쓰지 않는다.
과제명과 기획서에서는 대상을 분명히 밝히되, 아이가 매일 여는 화면에 진단명이 적혀 있으면
그 자체가 낙인이 된다.

## 어떻게 만들어졌나

```
브라우저(React)  →  Backend(FastAPI)  →  AI 서버(Meta Animated Drawings)
                         │                      └ 관절 찾기 · 애니메이션 만들기
                         ├ PostgreSQL · Blob 저장소
                         └ OpenAI (이야기 문장 · 검열 · 음성)
```

- **AI 서버는 바깥에서 부를 수 없다.** Backend만 부른다
- **외부 서비스 키는 Backend에만 둔다.** 화면은 업체 이름을 모른다
- **하나가 실패해도 이야기는 나온다.** 음성이나 영상이 없어도 문장은 만들어진다

자세한 구조는 [02 시스템 아키텍처](02-system-architecture.md)에 있다.
