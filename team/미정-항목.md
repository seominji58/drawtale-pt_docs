## 어떻게 쓰나

1. 정해지면 **해당 문서에 먼저 적고** 이 파일에서 지운다
2. 새로 발견한 빈칸은 여기에 적는다. **설계 문서에 「모른다」고 적지 않는다**
3. 발표 전에 이 파일을 훑어 **먼저 메울 것**을 고른다

아래는 **현장에 물어보지 않고 우리가 정한 것들**이다.
틀렸다면 설계를 통째로 다시 해야 할 수도 있다.

| A-11 | **아이가 카드를 보고 고른다** | **안 보고 누르면 「아이가 만든 이야기」가 성립하지 않는다** ([07 5-2](../07-user-research.md)) |

→ 검증 계획 · 질문 목록: [07 현장 자문 계획](../07-user-research.md)

### 수치로 정했지만 근거가 Meta 예제인 것

| 값 | 쓰임 |
|---|---|
| 검출 신뢰도 0.6 | 미만이면 어른 도움 링크 |
| 관절 점수 0.4 | 미만인 관절을 표시 |
| 관절 평균 0.35 | 미만이면 `LOW_CONFIDENCE` |
| 두 번째 검출 0.8 · 겹침 50% | 넘으면 `MULTIPLE_CHARACTERS` |

**아이들이 실제로 그린 그림으로 다시 재야 한다.**
지금 값은 Meta가 예제로 넣어 둔 그림에 맞춘 것이라, 아이 그림에서는 다르게 나올 수 있다.
그림을 어떻게 모을지는 [06 3장](../06-input-guideline.md)에 적었다.

## 아직 정하지 못한 것

| 무엇을 정해야 하나 | 지금 어떤 상태인가 | 누가 정하나 |
|---|---|---|
| 비회원이 로그인하면 그전 이야기는 | 비회원으로 만든 것은 주인이 없다. 로그인할 때 계정에 붙일지 | 전원 |
| 이메일 로그인을 남길지 (F-ACC-05) | 화면은 있는데 서버가 없다. 비밀번호를 받으면 지킬 것이 늘어난다 | 전원 |
| 이야기 카드 목록을 누가 들고 있을지 (F-STY-08) | 지금은 프론트에 있다. 서버로 옮길지 | 백엔드 · 기획 |
| 화면에 그린 그림은 AI를 건너뛸지 | 도장으로 그리면 관절 자리를 이미 아는데 그냥 버리고 AI에게 다시 묻는다 | 전원 |
| **화면에 그리기에 색칠을 넣을지** | 지금은 검정 한 색뿐이다. 색은 애니메이션에 그대로 쓰여서 결과물이 달라진다 (`06` 5-6) | 기획 · 프론트 |
| 약관 · 개인정보 처리방침 | 가입 화면이 가리킬 문서가 없다 | 기획 |
| 판정 기준값 4개 다시 재기 | 아이들 그림을 먼저 모아야 한다 | AI · 기획 |

첫 줄이 가장 급하다. 비회원으로 만든 그림과 이야기를 로그인 뒤에 이어서 볼 수 있게 할지 정해야 한다.

## 설계가 더 들어가야 하는 곳

적혀는 있으나 **한 겹만 파고 멈춘 곳**이다.

| 무엇 | 지금 | 더 들어가야 할 것 |
|---|---|---|
| **행동 카드와 영상이 따로 논다** | 행동 카드 6장 중 **「달려갔어요」만 점프**, 나머지 5장은 모두 손 흔들기 | **아이의 선택이 영상에 드러나지 않는다.** 「이야기를 구성하는 주체는 아이」와 부딪힌다 (`03` C-04b) |
| **이야기 카드 24장의 근거** | 카드는 정해져 있으나 **왜 이것들인지 없다** | 누가 고르고 누가 관리하나. 늘릴 수 있나 |
| **지원 수준을 누가 어떻게 고르나** | 수준별로 무엇이 바뀌는지는 있다 | 처음에 **어른이 무엇을 보고 고르나.** 안내가 없다 |
| **실패한 작업을 다시 돌리기** | Job 상태는 정의되어 있다 | 이야기 만들기가 실패하면 **처음부터 다시인지, 이어서인지** 없다 |
| **관절을 엉뚱한 곳에 찍으면** | 그림 밖인지만 본다 | 팔이 다리 자리에 가 있어도 통과한다 |
| **AI 세션 정리** | 만료 규칙이 없다 | AI 서버 디스크가 계속 찬다 |
